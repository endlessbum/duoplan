# DuoPlan — постоянные сведения

- Актуальное имя проекта и пакета: DuoPlan / duoplan. Не использовать старое имя WePlan в коде и конфигурации.
- Telegram-бот: https://t.me/duoplanbot.
- Стек: Python 3.11+, aiogram 3, aiosqlite/SQLite.
- Запуск из корня проекта: `.venv/Scripts/python.exe -m duoplan`.
- Локальная база по умолчанию: `data/duoplan.db`; секреты хранятся в `.env`.
- Концепция интерфейса: «Наше пространство», собственные спокойные тексты и оформление без копирования дизайна другого бота.
